# IMG-CP-14F · 내부 이미지 재연결 최종 감사

2026-11-03 · **PUBLICATION READY** · feature/subtitles의 내부 개발 체크포인트 24개 파일에 한정한다. 기준 HEAD와 upstream은 0f32bd6, main은 44943ea다. 감사 중 제품 및 테스트 소스는 수정하지 않았다.

## 두 차단 사유의 최종 판정

| 역사적 실패 | 현재 코드와 이번 재실행 |
|---|---|
| CP-14에서 열린 세션의 A를 이동하고 B로 재연결한 뒤 Undo하면 목록이 A를 사용 가능으로 표시했다. | RELINK-05는 취소·세션·세대·원본 revision을 확인한 뒤 missingMedia와 그 revision의 Undo 복원 정보를 함께 갱신한다. 이번 Undo는 누락 경고·재연결 버튼과 빈 프리뷰, Redo는 정상 행·교체 버튼과 B의 초록 프레임이었다. A를 원위치에 돌리고 다시 검증하면 빨간 프레임이 복구됐다. |
| CP-14R에서 검증 직후 URL을 이동시키면 ImageIO 두 번째 읽기가 실패해도 마지막 가용성 통지는 true였다. | RELINK-06은 같은 scope에서 읽기 접근 및 장치·inode·크기·수정 시각을 다시 확인한다. 기존 단언을 같은 시점에 실행한 Debug·Release 모두 계획 실패와 [true,false]를 관찰해 exit 0이었다. 두 옛 exit 1 기록은 보존했다. |

두 번째 읽기에서 확인된 소실·권한 거부·교체만 해당 원본을 사용 불가로 표시한다. 같은 파일을 다시 열 수 있지만 디코더가 거부하거나 자원 오류가 발생한 경우, 또는 OS 오류로 상태가 불확실한 경우에는 프리뷰 오류와 원본 가용성을 구별한다. 성공한 디코드도 업로드 전 식별값을 다시 비교한다.

## 구현 및 검증 범위

- 내부 빌드 및 런타임 게이트가 선택과 변경 진입점에 적용된다. 저장된 참조는 현재 접근 증명이 아니며, JPEG/PNG 후보를 전체 probe로 검사한다. 치수·방향 변경 확인 뒤 다시 검사하고 작업과 세션이 여전히 유효할 때만 북마크·원본·Undo 기록을 반영한다. 미디어와 클립 UUID, 시간·레인·변형, 다른 소스 편집을 보존한다.
- 메뉴 Undo와 키보드 경로는 각자 초점 조건을 확인해 편집 기록에 연결한다. 재구성 시 이전 이미지 계획을 취소하고 프리뷰 전용 오류를 새 세대에서 무효화한다. 후보 scope는 성공 시 세션에 이전하고 실패·취소 시 해제한다. 내보내기는 교체된 소스를 공유 계획에서 재검증한다.
- **새 실행**은 기존 jobs 1, 전용 APFS 캐시와 각종 자원 제한을 사용했다. Debug 및 Release 엔진 각각 51/51, 실패·건너뜀 0, exit 0. 미검증 소스 내보내기 거부, 기존 영상 컷, 색 평탄부 비교, 이동·교체·접근 거부·취소·디코더 거부를 포함한다. 별도 기존 엔진 시퀀스의 정상 및 두 번째 읽기 경계는 각각 두 구성 모두 exit 0이다. 이번에 새 결함 주입 시나리오는 추가하지 않았다.
- **새 서명 앱 실행**은 보존된 RELINK-06 Debug 번들의 strict/deep 서명을 다시 확인하고 새 생성 파일 및 격리 설정에서 수행했다. 앱/드라이버 exit 0, 71/71, scope 12/12, 시간 초과 없음. 같은 UUID에서 두 번째 읽기 실패와 복구는 세대 2/3, 일반 Undo/Redo는 세대 6/7이었다. 경고 행에서 실제 AVPlayerLayer 표시 버퍼는 없었고, B와 복구된 A의 중앙 sRGB는 각각 (2,248,2), (254,39,1)이었다. 행 캡처와 표시 버퍼를 별도로 확인했다. 처음부터 누락된 프로젝트·취소·후보 실패·다른 이미지 보호·같은 프로세스에서 저장 후 새 세션 열기도 이 실행에 포함된다.
- **이전 소유자 관찰**은 RELINK-02의 네이티브 재연결·치수 승인·새 프로세스 열기·내보내기, RELINK-03 수정판의 실제 마우스 메뉴 Undo/Redo다. 이번 메뉴 검사는 프로그램으로 실제 메뉴 항목을 호출했다. RELINK-06의 일반 패널 19/19, 단축키 44/44는 재사용한 증거다. 원래 파랑 G < 40 실패는 당시 exit 1로 남긴다. 실제 PNG의 G=51과 MP4의 G=51이 일치하며 기존 raw/MP4 평탄부 비교를 이번 엔진 회귀에서도 실행했다.
- [최종 후보 목록](IMG-CP-14F-MANIFEST.txt)은 현재 Git diff와 모든 비무시 미추적 파일을 대조해 만들었다. 로컬 증거 장부 app/selftest-work/img-cp14f-01/candidate-sha256.tsv에는 목록 자체를 포함한 24개 파일의 mode·SHA-256·저장소 상대 경로를 기록했다. 이전 16개 및 20개 후보 목록은 차단 시점의 증거로 보존한다. 설정·메타데이터 제외 4개, 원시 검사 출력과 생성 프로젝트·미디어·앱은 최종 후보 밖에 있다.

## 제한과 다음 단계

가용성 갱신은 기존 프리뷰 재검증에서 이루어진다. 지속 파일 감시는 없다. 8 MiB·최장 2048 px는 잠정 내부 제한이며 장기 scope 보유, 외장 볼륨, OS 권한 변경 및 고해상도 사용은 이번 검증 범위 밖이다. 개발용 서명이며 공개 이미지 게이트는 꺼져 있다. 형식 9와 스펙트럼 구현은 변경하지 않았다. 자막·스펙트럼·WMO 진단 컴파일 차단은 별도이며 스펙트럼 Stage 3C-2 및 Stage 4는 미구현이다. 다음 단계는 이 24개 후보에 대해 소유자가 별도 승인한 내부 체크포인트 커밋이다.
