# ON THE FRAME (온더프레임)

A macOS video editor for timeline editing, audio spectrum visualization, subtitles, and video export.

ON THE FRAME은 음악·플레이리스트 영상 제작과 일반 컷 편집을 위한 macOS 데스크톱 영상 편집기다. 영상·이미지·오디오를 타임라인에서 편집하고, 선택한 오디오를 따라 움직이는 오디오 스펙트럼과 수동 입력 자막을 얹어 영상으로 내보내는 것을 목표로 한다.

## 핵심 기능 (기획 brief 명시 요구사항)

- 영상·이미지·오디오 가져오기, 타임라인 편집(트림, 분할, 이동, 복사, 붙여넣기, 삭제), 실행 취소/다시 실행
- 오디오 스펙트럼 시각화 (After Effects의 Audio Spectrum을 참고)
- 수동 입력 자막 (타이밍, 폰트, 크기, 색상, 정렬, 위치)
- 영상 내보내기 (진행률, 취소, 실패 처리)
- 비파괴 편집, 프로젝트 저장/다시 열기, 누락 미디어 재연결

자세한 내용과 각 요구사항의 출처 구분(명시/파생)은 [docs/PRODUCT.md](docs/PRODUCT.md)를 참조한다.

## 제품 방향 (소유자 확인, 2026-10-09)

- 처음에는 소유자의 Mac에서 쓰는 개인용 앱으로 시작하고, 성공하면 상업 배포를 검토한다. 배포 채널, 라이선스, 활성화, 업데이트 권한, 결제는 미정이다.
- 가격 아이디어(약 20,000원, 일회 구매·평생 라이선스)는 잠정이며 확정이 아니다.
- 최대 3시간 프로젝트와 4K 편집·내보내기는 **지원 목표**다. 아직 구현·검증되지 않았다. 4K의 프레임레이트·HDR 등 세부는 미정이다.

## 현재 상태

**기획·실험 단계, 편집기 첫 마일스톤 M1 완료(2026-10-10).** 소유자 작업 승인 A-005~A-009로 [app/](app/)에 편집기 M1(영상 가져오기 → 배치 → 선택·분할·트림·이동·삭제 → 실행 취소·다시 실행 → 프리뷰 → 내보내기)을 구현했고, 자동 검증과 소유자 최종 확인(정성)을 거쳐 완료로 기록했다. M1 범위는 좁다: 입력은 30 fps 고정 간격 H.264·HEVC 영상(AAC 소리), 1920×1080 이하만 받고, 출력은 1920×1080 30 fps SDR H.264/AAC MP4, 영상 트랙 1개, 프로젝트 저장 없음. 복사·붙여넣기, 자막·스펙트럼, 이미지·오디오, 저장·다시 열기는 이후 마일스톤이며 시작하지 않았다. M2 전에 입력 호환 확장(A-010, 진행 중)으로 29.97·25·23.976·59.94 고정과 가변 프레임레이트 원본을 받게 했다(생성 fixture로 검증, 출력은 FHD 30 fps 그대로). ProRes, 4K, MKV 등은 아직 지원하지 않는다. 실제 29.97 fps 영상은 소유자 확인에서 정성적으로 동작했다. 가져오기·내보내기 진행 카드(경과·남은 시간 표시, A-011)를 진행 중이다. 알려진 열린 문제와 미확인 항목은 [app/README.md](app/README.md) §8·§10·§11에 있다. 소유자 작업 승인(A-001, A-002)에 따라 FHD 통합 실험 E1(헤드리스 내보내기 E1-a, 실제 `AVPlayer` 프리뷰 E1-b)을 [experiments/e1-fhd/](experiments/e1-fhd/)에 구현·실행했다. E1-b는 첫 소유자 관찰에서 프리뷰 화면 표시가 실패해 수정했고, 수정된 창은 소유자 재확인에서 정성적으로 통과했다(2026-10-10). 소유자가 끝 프레임 유지(D-018)와 E1 완료 기준을 정했고, 끝 프레임 유지를 구현했다. 끝 프레임 소유자 재확인도 통과해 **E1은 완료되었다(2026-10-10)** — 시험한 Mac 한 대의 짧은(10초) FHD 통합 실험에 한한다. E2(짧은 4K 컷 편집, A-003)를 구현·실행했다(2026-10-10): 헤드리스 검사는 모두 통과했다. 프리뷰 재생 시작 시 소스 프레임이 어긋나던 현상(직전 소스 버퍼 재전달 관찰)은 프레임 타이밍 변경 뒤 원래 조건에서 나타나지 않았지만, 변경 뒤 1회 관찰된 소스 프레임 불일치가 재현되지 않아 해결되지 않았다. 소유자 화면 관찰은 정성적 통과로 보고되었지만(2026-10-10) 이 정확도 결함을 해소하지 않으므로 E2는 완료가 아니다. 4K 제품 지원·3시간 지원을 입증하지 않는다. E3-1(10분 FHD, A-004)을 구현·실행했다(2026-10-10): 실행 완료. 첫 전체 실행의 검사 설계 실패 3건을 고친 뒤 보관 출력을 다시 검증해 통과했고, 프리뷰(디스플레이를 켠 실행)도 통과했다. 보관 MP4와 실시간 프리뷰의 소유자 정성 관찰을 거쳐 E3-1을 완료로 기록했다(시험한 Mac의 10분 FHD 첫 실행에 한함). 이 실험 코드는 제품 코드가 아니며, 4K·3시간 지원이나 제품 준비 상태를 입증하지 않는다. 기술 스택, 최소 macOS 버전, 입출력 포맷, 프로젝트 파일 포맷, 배포 방식, 라이선스는 모두 미정이다. 기술 방식 비교와 잠정 추천(미승인)은 [docs/TECHNOLOGY-EVALUATION.md](docs/TECHNOLOGY-EVALUATION.md)에 있다.
